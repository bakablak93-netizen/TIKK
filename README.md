# Сайт колледжа

Адаптивный сайт на Vite и JavaScript. Структура: главная, пять основных разделов, администрация, документы, контакты и конфиденциальность. Поддерживаются қазақша, русский и English. Сайт пока представляет собой фронтенд: CMS, отправка обращений и серверная обработка заявлений не подключены.

## Запуск

Требуется Node.js 22.12+ (проверяется на Node.js 24) и npm.

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

## Проверка и сборка

```sh
npm run build
npx playwright install chromium
npm test
```

Для Linux могут потребоваться системные библиотеки Chromium: `npx playwright install-deps chromium`.
Сборка находится в `dist/`, её можно разместить на статическом хостинге. Страницы используют hash-маршруты (`/#/ru/admissions`), поэтому серверные правила переписывания адресов не нужны. `npm run preview` запускает локальную проверку сборки.

## Файлы

- `src/main.js` — маршруты, языки и события.
- `src/layout.js` — шапка, навигация, подвал.
- `src/pages/home.js` — главная страница.
- `src/pages/content.js` — внутренние страницы.
- `src/locales/{ru,kk,en}.js` — отдельные словари интерфейса и содержания.
- `src/styles.css` — стили и адаптивная вёрстка.
- `public/media/` — место для фотографий и логотипа.
- `tests/site.spec.js` — браузерные проверки.

## Этап 4: официальные материалы

Название и сведения о колледже намеренно не выдуманы. Для заполнения нужны подтверждённые название, адрес, контакты, администрация, специальности и правила приёма. Переводы официальных материалов следует согласовать с колледжем.

Фотографии и логотип добавляются отдельными файлами в `public/media/` с осмысленными `alt`. Документы — в `public/documents/`, после чего добавляются действительные ссылки. Не используйте Base64. Абстрактные фигуры на главной созданы CSS и не изображают реальный кампус; знак рядом с названием — временный элемент макета, не официальный логотип.

До подключения формы обращений необходимы согласованный канал отправки, серверная обработка, защита от спама и утверждённая политика обработки данных. Сейчас кнопка «Связаться» открывает страницу контактов и не имитирует отправку обращения.

В подготовленной облачной среде уже установлен Chromium. Запуск проверок: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test`.
