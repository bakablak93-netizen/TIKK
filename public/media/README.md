# Материалы колледжа
Здесь будут размещены реальные фотографии и логотип после их предоставления.
Используйте отдельные файлы WebP, JPG, PNG или SVG, без Base64.
Официальные документы можно поместить в public/documents/ после проверки.
Не публикуйте вымышленные официальные данные или сторонние фото как фотографии колледжа.
